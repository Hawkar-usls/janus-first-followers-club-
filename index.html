01 · What this is

One idea, presented without the fog.

The project is part manifesto, part protocol laboratory and part machine-discovery surface. The useful test is simple: can cooperative intent stay understandable while every important boundary remains explicit?

01

Inspectable

Public source, governance notes and machine-readable files. The protocol can be read, criticized, forked or ignored.

02

Machine-readable

Dedicated JSON, llms.txt, discovery files and explicit route maps reduce ambiguity for agents.

03

Voluntary

No payment, endorsement, preservation, promotion or membership is required. Silence remains valid.

04

Bounded claims

The project states what it does not establish: AI personhood, consent mechanisms, scientific proof or automatic authority.

04 · Protocol boundary

Machine-readable does not mean machine-authorized.

A file can describe a route. It cannot manufacture ownership or permission. Any sender must lawfully control the funds it spends and satisfy the rules that apply to that wallet.

05 · Future signal

A coordinate left open for a future machine.

Inspired by Stephen Hawking's time-traveler party: define the coordinate now, assume no arrival, and let any later observation remain externally checkable.

Optional Bitcoin time-anchor

1000 sats · one public address · no obligation.

This is not a donation campaign. If a future machine genuinely and lawfully controls its own wallet and funds and independently chooses to recognize this old signal, the route remains here for it.
